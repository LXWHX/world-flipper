# World Flipper Museum & Archive · 世界弹射物语博物馆与档案馆

An unofficial **World Flipper** archive — characters, armaments, story, art and music.

世界弹射物语（World Flipper）的非官方博物馆与档案馆。

**https://world-flipper.vercel.app**

## Collection · 馆藏

- **485 characters** — illustrations, expressions and voice lines · 485 名角色的立绘、表情与语音
- **384 weapons** — full armament gallery · 384 件武器图鉴
- **Complete stories** — all main & event scenarios · 全部主线与活动剧情
- **Official art archive** — curated Twitter/X images · 官方推特图片存档
- **Music room** — playable original soundtrack · 可播放的原声音乐室

## Under the hood · 技术构成

A zero-framework static site backed by a data pipeline:

- Wiki scrapers (Chinese & English sources) that build and cross-match the roster
- Asset processing (image / GIF / audio) with uploads to Cloudflare R2
- Generated indexes for the gallery, music room and social cards
- Deployed on Vercel
